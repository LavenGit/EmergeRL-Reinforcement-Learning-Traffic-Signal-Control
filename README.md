Description

EmergeRL is a custom reinforcement learning environment built using Gymnasium, 
designed to simulate a realistic four-way traffic intersection with turning lanes, 
emergency vehicles, dynamic queues, and programmable traffic signal control.
The project implements SARSA and MAPPO (Multi-Agent PPO) agents and provides a real-time, animated visualization using Pygame.

Python version: Python 3.10

Install dependencies: pip install -r requirements.txt

Run the full Pygame simulation with RL: python pygame_test.py

Run the environment in terminal mode: python run_gymnasium_env.py
